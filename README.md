# Data-Necrosis

## Project Overview

**Data Necrosis** is a data analysis and visualization project designed to identify declining or inactive activity among products and customers using historical retail transaction data.

The project processes transaction data, removes invalid or incomplete records, calculates customer and product inactivity, and categorizes activity into different decay states such as **Active, At Risk, and Dormant**.

## Objectives

* Analyze historical retail transaction data.
* Clean and preprocess the dataset.
* Identify products and customers with declining activity.
* Calculate the number of days since the last recorded activity.
* Categorize products and customers based on their activity level.
* Visualize patterns of inactivity and customer/product decay.
